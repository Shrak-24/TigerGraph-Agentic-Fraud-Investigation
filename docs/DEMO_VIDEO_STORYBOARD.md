# Demo video storyboard (3-5 minutes)

| Time | Scene | What to show | Voiceover point |
|---|---|---|---|
| 0:00-0:20 | Hook | High-risk transaction alert | Signals alone do not explain whether to block. |
| 0:20-0:55 | Trigger | Agent opens a case from the alert | The investigation starts with a structured trigger. |
| 0:55-1:35 | Graph evidence | Transaction context, connected accounts, device cluster | TigerGraph exposes relationships that row-by-row review hides. |
| 1:35-2:10 | Grounding | Policy/pattern context and prior case retrieval | The agent grounds its assessment in policy and known patterns. |
| 2:10-2:45 | Uncertainty | Risk/confidence and missing evidence | High risk does not automatically mean irreversible action. |
| 2:45-3:20 | Next-best action | Step-up authentication with analyst approval gate | The agent recommends a controlled action and records the route. |
| 3:20-4:05 | Updated evidence | Simulated customer validation changes recommendation | The case progresses when new evidence arrives. |
| 4:05-4:40 | Audit trail | Final case record, explanation, and memory update | Every finding, decision, action, and outcome is traceable. |
| 4:40-5:00 | Close | Architecture and benchmark output | The same contract supports the graph, agent, and UI workstreams. |

Keep the demo focused on one case end to end; use the benchmark manifest as the final proof of repeatability.
